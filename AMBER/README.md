# amber-md-run

Tutorial on running protein-ligand simulations with the Amber MD engine.

## Instructions

Clone this repo then:

* If you are NOT using the CBA Jupyterhub or the Docker image, first execute `run_notebook.sh` in the root directory. This will install everything required, then launch the notebook from this directory with `jupyter lab amber-md-run.ipynb`.
* If you ARE using the CBA Jupyterhub, just open the file `amber-md-run.ipynb`.
